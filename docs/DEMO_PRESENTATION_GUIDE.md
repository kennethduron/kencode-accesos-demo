# Guía breve para presentar Ken Code Access

## Antes de la reunión

1. Abra `https://kencode-accesos.vercel.app`.
2. Compruebe que ambos dispositivos tengan internet estable.
3. Abra Residente y confirme que los escenarios ficticios cargan correctamente.
4. Abra Seguridad y pruebe la cámara con un QR de demostración.
5. En Residente, use **Restablecer escenarios demo** y confirme la acción.
6. Tenga dos dispositivos disponibles: uno para Residente y otro para Seguridad.

## Flujo recomendado

1. Muestre la landing y las tres experiencias disponibles.
2. Abra Residente.
3. Cree una visita **Familiar · 48 horas**.
4. Genere y muestre su QR.
5. Desde el segundo dispositivo, abra Seguridad y escanee el QR.
6. Confirme la entrada.
7. Regrese a Residente y muestre la actualización en tiempo real.
8. Vuelva a escanear el mismo QR.
9. Confirme la salida.
10. Escanee nuevamente el mismo QR y demuestre la reentrada.
11. Termine con la vista de Administración.

## Plan B

- Si la cámara falla, use el código manual mostrado debajo del QR.
- Si un dispositivo falla, use dos navegadores o dos pestañas y copie el código manual.

Todos los nombres, viviendas, vehículos y registros usados en la presentación son ficticios.
